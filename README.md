# 🐻 숲속 친구들 대작전

초등학생이 **각자 자기 기기(패드·크롬북·PC)** 로 접속해 3~5명이 한 모둠이 되어 하는 **3D 협동 퍼즐 게임**입니다.
숲속 동물 친구들이 힘을 모아 커다란 바구니(호박·꿀단지·선물 상자…)를 집까지 옮깁니다.
한 반 30명 내외(최대 8모둠 × 5명)가 동시에 할 수 있습니다.

## 수업 진행
1. 선생님: `주소/teacher.html` 을 TV에 띄우면 **방 코드(숫자 4개)** 가 나옵니다. **학급 이름**을 적어 두면 학급별로 별·기록이 이 컴퓨터에 저장됩니다.
2. 학생: `주소` 접속 → 방 코드 · 이름 · 모둠 → 대기실에서 **동물(곰·토끼·여우·판다·펭귄)** 고르기
3. 선생님: **[▶ 모든 모둠 시작]** (모둠마다 이어서 할 단계부터) 또는 모둠 카드에서 단계를 골라 시작
4. 모둠 카드의 **[👀 구경하기]** 로 그 모둠 화면을 TV에, **[🦉 함께하기]** 로 선생님이 부엉이가 되어 직접 참여

학생이 새로고침하거나 와이파이가 잠깐 끊겨도 **1분 안에 돌아오면 같은 자리로 자동 복귀**합니다.

## 미션 두 종류 (각 48단계 = 마을 8개)
- **👨‍👩‍👧 모둠 미션**: 학생 3~5명 모둠 (1·3·5명 + 선생님 함께하기까지 자동 검사)
- **👫 짝 미션**: 학생이 딱 2명인 모둠이면 자동으로 짝 미션. 비슷한 난이도로 둘이서 하기 좋게 새로 설계
  - **✋ 꾹 발판(보라색)**: 밟고 있는 동안만 보라 문이 열림 → 한 명이 문을 잡아 주고 친구가 지나감
  - **🎃 호박**: 친구들은 못 밀지만(벽처럼 막힘) 굴러오는 통나무·눈덩이에 밀려남. 꾹 발판 위로 밀려 가면 문을 열어 줌
- 별·기록은 짝 미션과 모둠 미션이 따로 저장됩니다.

## 🔮 '수수께끼 숲': 생각하는 협동 퍼즐 (모둠 6 + 짝 6단계)
퍼즐 6단계는 마지막에 몰려 있지 않고, 순서는 지키면서 다른 단계들 사이에 섞여 나옵니다 (1-4, 2-4, 3-1, 3-5, 4-5, 5-1 자리, 늘 같은 자리).
친구마다 **다른 일을 동시에** 해야 풀립니다. 각자 기기를 쓰는 점을 살려, 한 친구만 아는 정보를 말로 전해야 해요.
| 퍼즐 | 누가 무엇을 |
|---|---|
| 🔭 망루 길잡이 | 망루에 선 친구 **화면에만** 안개 늪의 징검다리가 보임 → 말로 길 안내, 다른 친구들은 바구니를 밀며 건넘 (늪에 빠지면 처음 자리로) |
| 🔢 그림 암호 문 | 표지판은 울타리 오두막 안에 있음. 문 앞 얼굴 발판을 먼저 밟은 친구 한 명만 들어갈 수 있고, 들어가면 문이 쾅 닫혀 못 나옴. 그 친구 **화면에만** 암호(⭐→🌙→❤️)가 보이고 그동안만 그림 발판이 눌림 → 읽어 주는 친구 + 밟는 친구. 도전할 때마다 암호가 바뀜 |
| 🚰 레버 | 레버 앞에서 ✋잡기를 누르고 있는 동안만 다리가 놓이거나 제방이 솟아 센 물살이 멈춤 → 레버 친구는 못 밀고, 나머지가 바구니를 옮김 (센 물살에 바구니가 연못으로 떠내려가면 처음 자리로) |

## 스스로 알아내기
학생 화면 맨 위에는 **최종 목표 한 줄만** 보입니다 (예: "🎯 호박을 🏠 우리 집에 갖다 놓아라!").
발판·레버·암호·망루가 어떻게 작동하는지는 알려 주지 않고, 아이들이 직접 해 보며 알아냅니다.
화면에는 "풍덩!", "🔓 문이 열렸어요!", "땡!"처럼 **무슨 일이 일어났는지만** 짧게 나옵니다.
바구니·호박을 물이나 구멍으로 밀면 **처음 자리**로 돌아갑니다. 레버 다리·꾹 발판 문·안개 늪·센 물살로 처음 자리와 땅이 끊긴 곳까지 옮겨 왔다면 **빠지기 직전에 있던 땅**으로 돌아갑니다 (단계가 막히지 않게). 물은 '풍덩!', 구멍(안개 늪·얼음판)은 '쏙!'이에요. 집 건물은 동물·바구니가 뚫고 지나갈 수 없어요 (바구니 길을 막지 않는 쪽에 세워짐).
막힌 모둠을 위한 **💡 힌트는 선생님 화면의 모둠 카드에만** 있습니다.

## 다시 해도 새로운 이유 (리플레이성)
같은 단계라도 **도전할 때마다 조금씩 달라집니다** (`shared/variant.js`).
| 바뀌는 것 | 내용 |
|---|---|
| 🪞 맵 뒤집기 | 좌우·위아래를 무작위로 뒤집음 → 단계마다 4가지 모양 (출발점·집 방향이 바뀜) |
| 🔭 망루 늪 길 | 징검다리 길을 매번 새로 만듦 (풀 수 있는지 바로 검사, 안 되면 다시 만듦) |
| 🍓 딸기 자리 | 걸어서 닿을 수 있는 곳 중 서로 떨어진 3곳을 새로 고름 |
| 🐝 장애물 타이밍 | 꿀벌·통나무·눈덩이·바위 출발 시점과 빠르기(±15%) 변경 (호박 퍼즐 단계는 설계대로 고정) |
| 📦 물건 자리 | 출발점·바구니·레버·망루·모둠 발판·바구니 발판·가시덤불·떨어진 연못을 조금씩(±25~50) 옮김 (풀 수 있는지 바로 검사) |
| 🔢 그림 암호 | 매번 새 암호 |
| ⭐ 별·기록·순위 | 별 3개, 새 기록, 모둠 별 순위, 학급별 기록 저장 |

`npm test` 가 모든 단계의 무작위 변형(단계마다 8가지)과 뒤집기 4가지가 **모두 풀 수 있는지** 검사합니다.

## 조작 (학생 화면)
- **왼쪽 조이스틱 = 이동, 오른쪽 조이스틱 = 화면 돌리기, 오른쪽 아래 = 잡기** (화면을 누른 자리에 조이스틱이 생김)
- 카메라: 기본은 **내 동물 뒤에서 내려다보는 시점**(왼쪽 위 작은 지도에 맵 전체). 🗺️/🎥 버튼 또는 `C` 키로 맵 전체 보기와 바꾸기
- 화면은 늘 북쪽(화면 위 = 지도 위)으로 고정. ⚙️ 설정에서 '화면 돌리기'를 켠 기기만 화면을 돌릴 수 있음
- PC: `WASD/방향키` 이동, `Q/E` 화면 돌리기, `Space` 잡기 · 게임패드: 왼쪽 스틱 이동, 오른쪽 스틱 화면, A 잡기

## 모둠 미션 48단계 · 8개 마을
단계 번호(1-1 ~ 6-6)는 나오는 차례입니다. 수수께끼 숲 퍼즐 6단계가 사이사이에 끼어 있어서, 아래 마을들은 그만큼 뒤로 밀려 나옵니다.

| 마을 | 새로 나오는 것 |
|---|---|
| 🌼 꽃밭 마을 | 바구니 밀기, 모둠 발판 문, 바구니 발판, 나뉜 발판 |
| 💧 시냇가 | 물(빠지면 처음으로), 물살, 굴러오는 통나무, 다리 |
| 🐝 꿀벌 숲 | 순찰하는 꿀벌, 가시덤불, 문 두 개 |
| ❄️ 눈 덮인 산 | 미끄러운 얼음, 굴러오는 눈덩이, 얼음 구멍 |
| 🌅 노을 계곡 | 진흙(느려짐), 굴러오는 바위, 문 세 개, 모든 장애물 |
| 🔮 수수께끼 숲 | 망루 길잡이, 그림 암호 문, 레버 다리·물살 (2명 이상) |
| 🌫️ 물안개 호수 (7-1~7-6) | 다리 두 개, 늪 건너 발판, 물살 위 다리, 구멍 숭숭 얼음판, 제방과 다리, 망루 두 개 (2명 이상) |
| 🏝️ 비밀 섬 (8-1~8-6) | 암호와 다리, 늪 속 다리, 섬 사이 징검다리, 늪과 물살, 얼음 늪, 물안개 대장정 (2명 이상) |

7·8번째 마을 12단계는 물·얼음 구멍·안개 늪·레버 다리·망루·물살·그림 암호를 섞은 단계로, 짝 미션에도 같은 장소가 있습니다 (`shared/levels-extra.js`). 맨 뒤에 붙여서 이미 저장된 별·기록은 그대로입니다.

모든 단계는 `npm test` 가 길찾기로 **풀 수 있는지** 자동 검사합니다 (모둠 미션 1·3·5·6명, 짝 미션 2·3명). 호박이 정말 밀려 움직이는지도 시뮬레이션으로 검사합니다.

## 규칙
| 규칙 | 내용 |
|---|---|
| 바구니 | 가벼움 1명 / 보통 절반 / 무거움 전원이 **같은 방향(±45°)** 으로 [잡기]를 누른 채 밀거나 당겨야 움직임. 2명 이상 필요한 바구니 위에는 `✋ 잡은 수/필요한 수`가 늘 보임 |
| 발판 문 | 인원 수만큼 발판 → **모두 동시에** 밟으면 문이 열림. 네모 발판은 바구니를 올려야 열림 |
| 벌칙 | 물·꿀벌·가시덤불·통나무·눈덩이·바위에 닿으면 **그 친구만 처음 자리로** (실수 +1, 1.6초 무적) |
| 물살 | 떠내려가지만, 바구니를 잡고 있으면 안 떠내려감 |
| 별 3개 | ⭐ 성공 · ⭐ 딸기 3개 모두 · ⭐ 목표 시간 안에 |

## 실행
```bash
npm install
npm start            # http://localhost:3100  (선생님: /teacher.html, 동물 미리보기: /animals.html)
npm test             # 규칙 + 30단계 자동 검사
node scripts/demo-bots.mjs 3 http://localhost:3100 1   # 로봇 3명 시연 (마지막 숫자 = 시작 단계, 로봇 2명이면 짝 미션)
node scripts/load-30.mjs                               # 학생 30명 동시 접속 시험
```

## 무료 운영 방법
- **A. Render 무료 서버**: GitHub에 올리고 Render에서 *New → Blueprint* 로 연결(`render.yaml` 자동 인식).
  15분 동안 접속이 없으면 잠들어서, **수업 1~2분 전에 선생님 화면을 먼저 열어** 깨워 두세요.
- **B. 교사 PC를 서버로**: 교사 PC에서 `npm start` → 학생들은 `http://교사PC의IP:3100` 접속.
